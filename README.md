# Guide-generator

Web-based RestedXP guide generator.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Current status
- BattleTag validation
- Latest RestedXP release lookup
- Import-code UI
- Copy-to-clipboard
- Responsive dark UI

The real RestedXP account-bound import generation must be connected to an authorized server-side implementation; the app never invents a fake import code.
